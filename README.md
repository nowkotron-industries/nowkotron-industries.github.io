# Nowkotron Industries

Web de Nowkotron Industries, publicada con GitHub Pages en https://nowkotron-industries.github.io/

- `ciclo/privacidad/`, `ciclo/privacy/`, `ciclo/privacidade/`, `ciclo/privadesa/`: política de privacidad de Ciclo en español, inglés, portugués y catalán.
- Las páginas se generan con `python tools/build.py`. El texto se edita ahí, no en los HTML.
